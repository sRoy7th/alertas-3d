# Alertas 3D

Alertas animadas en 3D para Twitch (Three.js), pensadas para un Custom Widget de StreamElements.

- `index.html?test`: panel para probar cada alerta en el navegador
- `streamelements/`: archivos para pegar en el widget (se generan con `python tools/build_se.py`)
- `models/`: modelos .glb optimizados (se generan con `tools/optimize.py` en Blender)
